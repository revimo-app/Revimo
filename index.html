3 · Filtres des biens enregistrés

Par défaut, aucune limite de prix ni de marge. Toutes les catégories de travaux, y compris lourds, sont visibles. Les filtres n'effacent jamais les annonces.

Le score combine marge et rendement estimés. La « marge » utilisée ici reste avant fiscalité sur les bénéfices : elle ne constitue pas encore une plus-value nette fiable.

☁ Synchronisation téléphone / PC

Connexion facultative à ton propre projet Supabase gratuit. Tes annonces restent utilisables localement sans compte. Pour la synchronisation, ouvre cette application depuis une adresse HTTPS sur les deux appareils (un simple fichier local n’est pas recommandé).

Le PIN est configuré séparément sur chaque appareil : choisis les mêmes 4 chiffres sur ton téléphone et ton PC. Il protège la session enregistrée localement. En cas d'oubli, reconnecte-toi avec ton e-mail et ton mot de passe.

Les transferts sont déclenchés manuellement dans cette version afin d’éviter l’écrasement accidentel de données. « Récupérer » remplace la base locale après confirmation. « Envoyer » remplace la sauvegarde cloud après confirmation. Ne partage jamais ton mot de passe ni une clé secrète.

Configuration initiale du cloud (une seule fois)

1. Crée un projet sur Supabase. 2. Dans SQL Editor, exécute le script SQL fourni avec cette version. 3. Dans Authentication, configure la connexion par e-mail. 4. Copie l’URL et la clé publique du projet ci-dessus. 5. Crée ton compte, confirme l’e-mail si nécessaire, puis connecte-toi.
